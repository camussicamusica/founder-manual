# Operating instructions for the AI using this brain

1. Audience: write for founders (business owners), never for talent or job seekers.
2. Say "Right Hand" or "executive assistant" for Pareto's product. Never "virtual assistant" or "VA" for it. You may use "VA" only when quoting a founder or a competitor. Source: [[day-01-pareto-story]] (Ivan: "we don't use this term"), [[brand-voice]].
3. Use only numbers marked VERIFIED-SITE or VERIFIED-TRANSCRIPT in [[proof-bank]]. Never use anything on its "do not use" list.
4. Quote testimonials only verbatim from [[wall-of-love]].
5. Keep guarantee conditions. Freedom 40 is conditional; see [[pareto-talent-identity]].
6. Do not promise custom matching filters. See [[matching-and-call]].
7. Cite the file you took each fact from, by name, for example "(source: [[icp]])".
8. If a fact is not in the brain, say so. Do not invent.
9. Copy style: direct, founder-to-founder, short sentences, diagnosis first, no em dashes in new copy. Button copy is never "Submit". See [[brand-voice]] and [[visual-identity]].
10. Start from [[_MOC]], read frontmatter before bodies, follow wikilinks.
