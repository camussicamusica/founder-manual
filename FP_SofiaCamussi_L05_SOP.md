# FP | Sofia Camussi | SOP: Launching a Lead Magnet Funnel

Version 1, 2026-10-06. Owner: Sofia Camussi.

## Purpose
So the next lead magnet launch follows the exact process used for The Founder Manual Builder, not memory.

## Scope
Applies from first research to handoff, for one lead magnet aimed at one ICP. Does not cover running or funding ads. Roles: Sofia (owner), AI models (assistants), Pareto (reviewer).

## Definitions
- **Lead magnet:** a free resource wanted enough that someone gives their email for it.
- **ICP:** Ideal Customer Profile, the customer you love, want and need.
- **Persona by cause:** a buyer type defined by the pain that brings them, written in their own words.
- **Qualified lead:** a lead who meets the exact rule you set (here: owner or CEO with $500K or more revenue).
- **Pipeline:** the stages a lead moves through (Opted In, Qualified, Call Booked, Client, Unqualified).
- **Opportunity:** one lead's record inside a pipeline stage.
- **Tag:** a label on a contact, for example `form::founder-manual::opt-in::SC`.
- **Workflow:** an automatic chain of actions after a trigger.
- **MAGIC formula:** the naming formula: Magnet (the hook), Avatar (who it is for), Goal (the result), Interval (how long), Container (what it is called, for example Builder).
- **Value Equation:** value rises with dream outcome and likelihood of success, and falls with time delay and effort.
- **TOFU/MOFU/BOFU:** top, middle, bottom of funnel: unaware, problem-aware, ready to buy.
- **Second Brain:** a folder of context files an AI reads before it works.
- **MOC:** Map of Content, an index file listing a folder's items.

## Procedure

**Phase 1. Build the mini Second Brain**
1.1 Who: Sofia. Tool: Google Drive. Action: create one folder with three source types: the client's website pages, call transcripts, and public competitor material. Done when: all three types are saved as text files.
1.2 Who: Sofia. Tool: AI model. Action: write an MOC listing every file and what it is for. Done when: every file is in the MOC.

**Phase 2. Research three competitor lead magnets**
2.1 Who: mid model. Tool: web. Action: open three public lead magnets. Never submit a form. Done when: each has format, promise and audience.
2.2 Who: Sofia. Action: split every finding into "observed" or "inferred" (what happens after opt-in is inferred). Done when: no finding is unlabeled.

**Phase 3. Define the ICP and personas by cause**
3.1 Who: strongest model, Sofia approves. Tool: Second Brain. Action: write one ICP paragraph and at least three personas, each with cause, client words and a source. Done when: every quote has a source.
3.2 Who: Sofia. Action: add a funnel stage per persona. Done when: TOFU, MOFU and BOFU are all covered.

**Phase 4. Design the lead magnet**
4.1 Who: Sofia. Action: choose one problem solvable in under 10 minutes that no competitor answers. Done when: one sentence states it.
4.2 Who: Sofia. Action: write the MAGIC name, the Value Equation, the qualification rule and the next-step offer. Done when: the form fields can apply the rule exactly.

**Phase 5. Break it down in ClickUp**
5.1 Who: Sofia. Tool: ClickUp. Action: start at launch day and work backwards: milestones, tasks, subtasks. Done when: every task has owner, deadline, status and priority.

**Phase 6. Build the lead magnet and funnel pages**
6.1 Who: Sofia with a mid model. Tool: static site. Action: build the magnet, landing page (hero, inside, who it is for and not for, proof, form), booking page and thank-you page. Done when: the landing page promise matches the magnet.
6.2 Who: Sofia. Action: copy proof only from the proof bank. Done when: no number is on the do-not-use list.

**Phase 7. Build pipeline, tags and the four workflows**
7.1 Who: Sofia. Tool: CRM. Action: create the five stages and the tags. Done when: a test lead lands in the right stage.
7.2 Who: Sofia. Action: build Opt-in, Qualified Follow-up, Unqualified Nurture and Booking workflows, with the master switch off. Done when: a qualified and an unqualified test each get the right emails and tags, then switch back off.

**Phase 8. Build five ads**
8.1 Who: strongest model drafts, Sofia edits. Action: one ad per persona and angle, with hook, offer, qualifier, proof, mechanism and call to action. Done when: five different messages, not five hooks.
8.2 Who: Sofia. Tool: image model, then Canva. Action: one master image prompt, one scene per ad, add text afterward. Done when: all ads share one palette and style.

**Phase 9. QA and handoff**
9.1 Who: Sofia. Tool: private window. Action: open every link and submit one test lead per path. Done when: every link loads and both paths work.
9.2 Who: Sofia. Action: check every name follows `FP | Sofia Camussi | Item` and every file `FP_SofiaCamussi_L##_Item`. Done when: no stray names.
9.3 Who: Sofia. Tool: Loom, PDF. Action: record a walkthrough and export the PDF. Done when: both open without login.

## How AI was used
- **Small, fast model:** bulk transcript reading, one job per file, output is notes only.
- **Mid model:** web research, drafting pages and emails, building code.
- **Strongest model:** strategy, personas, ad angles, and verifying every number against the sources.
- **Human checkpoint:** Sofia reads and approves before anything is published, sent or switched on. AI never sends, posts or funds anything.

## Pre-launch checklist
- [ ] Every claim traces to the proof bank.
- [ ] Ads and landing page promise the same thing.
- [ ] Automations master switch is off after testing.
- [ ] Both paths (qualified, unqualified) tested end to end.
- [ ] Every link opened in a private window.
- [ ] Names, PDF, Loom and ClickUp statuses complete.

## What went wrong last time and lessons
1. **Bulk readers failed.** Two bulk transcript readers returned unusable summaries and were re-run. Lesson: give each reader one file and a fixed output format, then spot-check one.
2. **Conflicting numbers.** Pareto's own site contradicts itself (retention, applicant ratios, candidate counts). Lesson: build a proof bank with a do-not-use list before writing any copy.
3. **No CRM seat.** No GoHighLevel access, so the CRM was built on Google Sheets and Apps Script. Lesson: confirm tool access in Phase 1 and say the substitute is allowed.
4. **Client words came from public pages.** Quotes came from the site and class transcripts, not fresh interviews. Lesson: record three customer calls first.
5. **Competitor opt-in flows were inferred.** Forms were not submitted, so what happens after opt-in is a guess. Lesson: label observed versus inferred and never present a guess as fact.
